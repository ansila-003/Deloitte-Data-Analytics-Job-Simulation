# 📊 Task 1 – Data Analysis

## 🎯 Objective

Analyze telemetry data to identify downtime patterns across factories and device types.

## 🔧 What I Did

- Analyzed the telemetry data provided for the simulation
- Created Tableau visualizations to analyze downtime by factory and device type
- Created a dashboard showing:
  - Downtime per Factory
  - Downtime per Device Type
- Identified the factory with the highest downtime
- Applied a factory filter to show the corresponding device-type downtime
- Created and saved the completed Tableau dashboard

### 🛠️ Tool Used

**Tableau**

# 🔎 Task 2 – Forensic Technology

## 🎯 Objective

Review employee compensation data and classify equality scores according to the task requirements.

## 🔧 What I Did

- Worked with the compensation equality dataset provided for the simulation
- Used the existing columns:
  - Factory
  - Job Role
  - Equality Score
- Added a fourth column:
  - Equality Class
- Classified the equality scores into:
  - **Fair**
  - **Unfair**
  - **Highly Discriminative**
- Saved the completed Excel file

### 🛠️ Tool Used

**Microsoft Excel**
